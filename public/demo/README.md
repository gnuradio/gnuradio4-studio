# Payload fixtures

Waterfall payloads for parser tests and manual inspection:

- `waterfall-spectrum-json-v1.normal.json`: normal payload
- `waterfall-spectrum-json-v1.smallest.json`: smallest valid payload
- `waterfall-spectrum-json-v1.malformed.json`: invalid payload for error checks

See [payload contracts](../../docs/studio-blocks-payload-contracts.md) for field definitions and validation steps.

For live plots, use [studio-blocks-waterfall.gr4s](../../examples/studio-blocks-waterfall.gr4s) or [studio-blocks-sidebands.gr4s](../../examples/studio-blocks-sidebands.gr4s). The latter includes the phosphor spectrum view.

Other flowgraphs and their controls are listed in [examples/README.md](../../examples/README.md).
