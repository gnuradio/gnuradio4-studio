# Sample themes

Import `midnight.gr4stheme` using **Appearance → Import Theme…**, then choose
**Midnight** in the theme selector to apply it. Importing alone keeps your current
theme selected.

Midnight overrides application and flowgraph colors with a violet night palette.
Unspecified tokens inherit from Dark. Port type colors retain Studio's fixed
semantic palette across all themes.

To check management and persistence, export Midnight, reimport it to exercise
replacement confirmation, and reopen Studio to verify your selection is restored.
Deleting Midnight while selected should switch back to Dark.
